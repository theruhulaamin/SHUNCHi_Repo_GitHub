How to get a free Gemini API key for SHUNCHi (step by step)

SHUNCHi uses your own free Google Gemini API key for speech recognition. Here is how to create the key in a minute and paste it into Settings.

SHUNCHi turns your speech into text using Google's Gemini. To keep the app free for everyone, it uses your own free API key instead of a paid subscription. Creating the key takes about a minute.

What is an API key?

An API key is a long private code that lets an app use a Google service on your account. Think of it as a password for one purpose. Do not share it publicly.

Step 1: Open Google AI Studio

Go to aistudio.google.com/apikey and sign in with a Google account. Any normal Google account works.

Step 2: Create the key

Choose Create API key. Select an existing project or let Google create one for you. The key appears on screen. Click the copy button and copy the whole key. It is long and usually starts with "AIza".

Step 3: Paste it into SHUNCHi

  1. Open SHUNCHi and go to Settings.
  2. Paste the key into the Gemini API key box.
  3. Choose Save & test.

When a green Connected label appears, you are ready to use voice typing. See the full setup guide for the next steps.

If the key is rejected

  • Copy the key again and make sure there are no spaces before or after it.
  • Check that the Gemini API is available in your country.
  • Create a new key and try again.

About the free limits

Google's free tier has daily limits. If you reach the limit, SHUNCHi tells you, and it works again after the limit resets. For the most current limits, check Google AI Studio.

Where is my key stored?

Your key is stored in Windows Credential Manager on your own PC. It is not sent to this website.
