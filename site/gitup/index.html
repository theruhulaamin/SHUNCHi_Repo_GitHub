Release a new version

Step by step. When it is done the Download page and the in-app update notice update by themselves.

Step 1: Prepare

English

  1. On your Windows PC open the project folder and double-click app\Build_Installer.bat.
  2. Wait until it says it finished. Two files appear in the release folder:
    SHUNCHi_Setup_X.Y.Z.exe (full installer) and SHUNCHi_Setup.exe (small web installer).
  3. Install it once on your PC and check that dictation works.
  4. Press Next.

বাংলা

  1. আপনার Windows PC-তে প্রজেক্ট ফোল্ডার খুলে app\Build_Installer.bat ডাবল ক্লিক করুন।
  2. "finished" লেখা না আসা পর্যন্ত অপেক্ষা করুন। release ফোল্ডারে দুটি ফাইল তৈরি হবে:
    SHUNCHi_Setup_X.Y.Z.exe (পুরো ইনস্টলার) ও SHUNCHi_Setup.exe (ছোট ওয়েব ইনস্টলার)।
  3. নিজের PC-তে একবার ইনস্টল করে ডিকটেশন চলছে কিনা দেখুন।
  4. Next চাপুন।

English

  1. Build your .exe or .zip file. One file is enough.
  2. Keep the version number ready (like 1.2.0).
  3. Press Next.

বাংলা

  1. আপনার .exe বা .zip ফাইল বানিয়ে নিন। একটি ফাইলই যথেষ্ট।
  2. ভার্সন নম্বর (যেমন 1.2.0) ঠিক করে রাখুন।
  3. Next চাপুন।

Create the access token (one time)

English

  1. Open GitHub, new fine-grained token.
  2. Name: SHUNCHi admin. Expiration: 90 days to 1 year.
  3. Repository access: Only select repositories, choose this repository.
  4. Permissions, Repository: Contents = Read and write, Actions = Read and write, Administration = Read (optional, for visitor numbers), Metadata = Read.
  5. Press Generate token, copy it and paste it on the connect screen.

বাংলা

  1. GitHub-এ নতুন fine-grained token পেজ খুলুন।
  2. নাম: SHUNCHi admin। মেয়াদ: ৯০ দিন থেকে ১ বছর।
  3. Repository access: Only select repositories, তারপর এই রিপোজিটরি বাছুন।
  4. Permissions, Repository: Contents = Read and write, Actions = Read and write, Administration = Read (ঐচ্ছিক, ভিজিটর সংখ্যার জন্য), Metadata = Read।
  5. Generate token চেপে কপি করুন এবং কানেক্ট পেজে বসান।

The token works only for this repository. Never share it. When it expires, press Regenerate in GitHub.

After you publish

Changes go live in about 2 minutes. To get found faster, paste the new page address into Search Console “URL inspection” and press “Request indexing”.

Security

  • The token stays in your browser and never goes to any server.
  • Never use “Remember” on someone else's computer and press Disconnect when done.
  • Keep 2FA on for your GitHub account.
