Release a new SHUNCHi version

This is the safe 4-step flow. The website and the in-app update notice update by themselves once you publish the release on GitHub.

  1. On your PC run Build_Installer.bat. It creates release\SHUNCHi_Setup_X.Y.Z.exe and release\SHUNCHi_Setup.exe.
  2. Type the version below and press the button. GitHub opens a release page with the tag ready.
  3. Attach both .exe files, write a short note, press Publish release.
  4. Wait about 3 minutes. The Download page and the in-app update banner now show the new version.

How to create the access token (one time)

  1. Open GitHub, new fine-grained token.
  2. Name: SHUNCHi admin. Expiration: 90 days (renew when it expires).
  3. Repository access: Only select repositories, then choose this repository.
  4. Permissions, Repository: Contents = Read and write, Actions = Read and write, Metadata = Read.
  5. Press Generate token, copy it, paste it on the connect screen.

The token works only for this repository. Keep it private. If you ever lose control of it, delete it in GitHub and make a new one. Use "Remember on this device" only on your own computer.

After you publish

Changes go live in about 2 minutes. In Google Search Console (see docs/ADMIN_SEO_BN.md) you can paste the new page address into "URL inspection" and press "Request indexing" to be found faster.
