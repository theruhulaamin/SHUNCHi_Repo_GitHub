SHUNCHi 4.3.0 — Simple, Fast and Polished
==========================================

WHAT CHANGED (based on real-world testing of 4.2.0)

1. Voice to text is now ONE simple step
   - Old: live WebSocket + separate AI polish + backup (three things that could fail).
   - New: your speech is recorded, trimmed of silence, and sent once to Gemini 3.5 Transcribe in
     "Smart" mode, which already removes filler words, adds punctuation and formats lists.
     If that model is unavailable, a plain request and then Gemini 3.8 Flash are tried automatically.
   - The API key is sent in a request header (never in a URL) and is removed from every log line.
   - Real error messages: invalid key, quota reached, no internet, no model access, no speech.
   - Removed dependencies: google-genai, websockets, SciPy, PyAutoGUI (smaller, safer build).

2. Auto-stop now works
   - New adaptive voice detector: it learns the room noise, keeps adapting during pauses, and stops
     after your chosen silence (default 1.2 s). Tested with quiet rooms, noisy fans, quiet speakers,
     short pauses inside a sentence, key clicks and silence.

3. Voice popup redesigned
   - Compact, clean, professional: live voice line, timer, status pill, tiny credit line.
   - No transcript is shown in the popup. When you finish, the polished text is typed at your cursor.
   - States: Listening, Writing, Done, Notice (with a readable message).

4. Dashboard and every menu redesigned
   - Light, minimal design system with drawn vector icons (no emoji icons).
   - Dashboard: status banner, shortcut cards, "Try it here" box.
   - Voice History: simple searchable list with Copy and Clear only.
   - Settings: auto-saving options with real on/off switches.
   - Fixed the boxed labels, cropped header and ugly scroll bars seen in 4.2.0.

5. Start with Windows is now a Settings switch (on/off at any time) and an installer option
   (selected by default).

6. Installer
   - Per-user install: no administrator prompt.
   - New clean wizard artwork (sharp on high-DPI screens), shorter wizard, friendly welcome and
     finish text, "Start with Windows" selected by default.

7. Other fixes
   - Gemini Live is no longer needed; its 10-minute limit and setup problems are gone.
   - Long dictations are sent in 2-minute pieces so they never hit request-size limits.
   - A hard time limit prevents a slow network from freezing the popup.

NOTHING WAS REMOVED THAT YOU USE: all pages, shortcuts, history, developer information, support
links, credits and assets remain.

SHUNCHi 4.2.0 — Final Stability Release
=======================================

CRITICAL FIXES (these caused the repeated failures in earlier builds)
- Fixed a startup crash: the main window connected to a "live_error" signal that did not exist,
  so the app raised an error before the Dashboard could open.
- Fixed Gemini Live always being reported as "setup did not complete": the server confirms setup with
  an EMPTY object ({"setupComplete": {}}), which the old code treated as "no reply". Live captions
  now connect correctly. Same fix in the API Test.
- Fixed the Live-failure handler (it called a missing helper), so the backup transcription path is now
  reliably armed when Live drops. A broken connection is also noticed immediately instead of only
  after you stop speaking, and the worker can no longer hang on exit.
- Fixed literal "\n" text in error messages, How-to-use page, History view and "Copy all".
- Fixed log redaction when no API key is present (it could insert "[redacted]" between every character).
- An empty polished transcript no longer leaves the popup stuck.

GEMINI API ALIGNMENT (verified against the current Google documentation)
- Models unchanged: gemini-3.5-transcribe-live, gemini-3.5-transcribe, gemini-3.8-flash.
- Requests use the v1beta endpoint. Gemini 3.8 Flash ignores temperature, so it is removed;
  thinking_level LOW is used for fast polishing/backup (MINIMAL is rejected by 3.8 Flash).
- The polish prompt now treats the transcript strictly as text to edit (it will not answer questions
  spoken inside the dictation) and a length safety check keeps the original if the model misbehaves.
- API errors are translated into short, actionable messages (invalid key, quota, no internet, no access).

AUDIO
- New stateful NumPy resampler (44.1/48/32/24 kHz -> 16 kHz). The old per-chunk resampling created a tiny
  click every 100 ms, which hurts Bangla recognition. SciPy is no longer needed (smaller, safer build).

PASTE
- Auto-paste now uses the Windows SendInput API (PyAutoGUI removed) and waits until Win/Ctrl/Shift/Alt are
  released before pasting, so text no longer lands as a shortcut. Clipboard is restored afterwards.

UI / UX
- Popup redesigned: vector microphone mark (no emoji font), 40 bars that scroll with the real voice, blue
  gradient progress, coloured status pill (LIVE / BACKUP / ERROR / DONE), opens on the screen where the
  mouse is.
- Dashboard: new "Try it here" practice box for first-time users.
- Closing the window shows a one-time tray hint. Start-with-Windows launches minimised in the tray.
- Log file is size-limited (rotating).

INSTALLER / BUILD
- Build_Installer.bat now checks the source and dependencies before building, uses CRLF line endings, and
  builds a much smaller package (no collect-all of PySide6/SciPy).
- Installer: same AppId (upgrades 4.1.4 in place), removes stale _internal files on upgrade, stops a running
  SHUNCHi.exe on uninstall, requires Windows 10 or newer.

NOTHING WAS REMOVED: all pages, shortcuts, history, developer info, assets, support links, installer
wizard images and documents are retained.

  of aborting on the first receive timeout.

  when no text part exists, and falls back to candidate audio-transcription parts.
