# শুনছি: Production বিল্ড ও রিলিজ গাইড

## ১. একবারের প্রস্তুতি (নিজের Windows পিসিতে)
1. **Python 3.13 (64-bit)** ইনস্টল করুন (python.org, "py launcher" টিক দিন)।
2. **Inno Setup 6.4 বা নতুন** ইনস্টল করুন (jrsoftware.org/isdl.php)। ওয়েব ইনস্টলারের জন্য ৬.৪+ লাগবে।
3. এই রিপোর `app` ফোল্ডারটি পিসিতে রাখুন (GitHub থেকে ডাউনলোড বা clone)।

## ২. বিল্ড (প্রতিবার)
1. ভার্সন বদলাতে **শুধু `app/app.py`-র এই লাইনটি** বদলান (৩ অংশের ভার্সন, যেমন `4.5.0`):
   `APP_VERSION = "4.5.0"`
2. `app/Build_Installer.bat`-এ ডাবল ক্লিক করুন। ৫-১০ মিনিট লাগে।
3. শেষে `app/release` ফোল্ডারে দুটি ফাইল পাবেন:
   - `SHUNCHi_Setup_4.5.0.exe` (পুরো ইনস্টলার)
   - `SHUNCHi_Setup.exe` (ছোট ওয়েব ইনস্টলার, প্রতি রিলিজে একই নাম)
4. **নিজের পিসিতে আগে পরীক্ষা করুন:** পুরো ইনস্টলার চালিয়ে ইনস্টল, ডিকটেশন, আনইনস্টল দেখুন। সম্ভব হলে অন্য একটি পিসি বা Windows Sandbox-এও চালান।

## ৩. রিলিজ (GitHub Releases, অ্যাডমিন প্যানেল)
1. GitHub রিপো → **Releases → Draft a new release**।
2. **Tag:** `v4.5.0` লিখে "Create new tag on publish" বেছে নিন।
3. **Title ও Description:** কী নতুন তা বাংলা/ইংরেজিতে ২-৩ লাইনে লিখুন (এটাই অ্যাপের আপডেট বার্তায় দেখাবে)।
4. `app/release` ফোল্ডার থেকে **দুটি .exe-ই** ড্র্যাগ করে অ্যাটাচ করুন।
5. **Publish release** চাপুন।
6. প্রায় ৩-৫ মিনিটে অটো হয়ে যায়: `update.json` আপডেট (SHA-256 চেকসাম সহ) → ওয়েবসাইট ডিপ্লয়। **Actions ট্যাবে সবুজ ✓** দেখে নিন।
   - কোনো একটি .exe না দিলে workflow ইচ্ছা করেই ফেল করে, যাতে ভুল রিলিজ কেউ না পায়।

## ৪. ইউজারদের কাছে কী হয়
- **নতুন ইউজার:** shunchiai.com/download → `SHUNCHi_Setup.exe` (প্রায় ৩ MB) নামান → ডাবল ক্লিক → এটি shunchiai.com থেকে সর্বশেষ ভার্সনের তথ্য নিয়ে GitHub থেকে পুরো ইনস্টলার নামায়, SHA-256 মিলিয়ে দেখে, তারপর চালু করে।
- **পুরনো ইউজার:** অ্যাপ নিজে প্রতি ~৬ ঘণ্টায় (বা চালু হলে) নতুন ভার্সন খোঁজে, ব্যানারে "Download" বাটন দেখায়। পুরনোটার ওপরেই ইনস্টল করলে সেটিংস ও কী থাকে।

## ৪.১ নিরাপত্তা
- ওয়েব ইনস্টলার শুধু `https://github.com/theruhulaamin/` রিলিজ লিংক নেয় এবং চেকসাম না মিললে ফাইল চালায় না।
- ইনস্টলার **সাইন করা নয়**, তাই প্রথমবার Windows SmartScreen "More info → Run anyway" দেখাবে। Code-signing সার্টিফিকেট (বছরে কিছু টাকা) কিনলে এটি কমে।

## ৫. সমস্যা হলে
- বিল্ডে এরর: পুরো এররের স্ক্রিনশট পাঠান।
- ওয়েব ইনস্টলার "No installer is published yet": রিলিজ এখনও Publish হয়নি, বা Actions-এর `Release update` ফেল করেছে। Actions ট্যাব দেখুন।
- রিপোর নাম বদলালে `app/SHUNCHi_Web.iss`-এর `AllowedPrefix` ঠিক আছে কিনা দেখুন।
