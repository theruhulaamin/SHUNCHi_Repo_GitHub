শুনছি আপনার কথা লেখায় রূপান্তর করতে গুগলের Gemini ব্যবহার করে। অ্যাপটি সবার জন্য ফ্রি রাখতে এটি কোনো পেইড সাবস্ক্রিপশনের বদলে **আপনার নিজের ফ্রি API কী** ব্যবহার করে। কী বানাতে প্রায় এক মিনিট লাগে।

## API কী কী?

API কী হলো একটি লম্বা গোপন কোড, যা দিয়ে কোনো অ্যাপ আপনার অ্যাকাউন্টে গুগলের সেবা ব্যবহার করতে পারে। এটাকে একটি নির্দিষ্ট কাজের পাসওয়ার্ড ভাবতে পারেন। কাউকে প্রকাশ্যে দেবেন না।

## ধাপ ১: Google AI Studio খুলুন

`aistudio.google.com/apikey` ঠিকানায় যান এবং গুগল অ্যাকাউন্ট দিয়ে সাইন ইন করুন। যেকোনো সাধারণ গুগল অ্যাকাউন্টে হবে।

## ধাপ ২: কী তৈরি করুন

**Create API key** চাপুন। আগের কোনো প্রজেক্ট বেছে নিন, অথবা গুগলকে নতুন একটি বানাতে দিন। কী-টি পর্দায় দেখা যাবে। কপি বাটনে ক্লিক করে পুরো কী কপি করুন। এটি লম্বা হয় এবং সাধারণত "AIza" দিয়ে শুরু হয়।

## ধাপ ৩: শুনছিতে বসান

1. শুনছি খুলে **Settings**-এ যান।
2. Gemini API key বক্সে কী-টি পেস্ট করুন।
3. **Save & test** চাপুন।

সবুজ **Connected** লেখা এলে ভয়েস টাইপিং ব্যবহারের জন্য তৈরি। পরের ধাপগুলোর জন্য [পুরো সেটআপ গাইড](/index.html#setup) দেখুন।

## কী গ্রহণ না করলে

- কী আবার কপি করুন এবং আগে-পরে কোনো ফাঁকা জায়গা আছে কিনা দেখুন।
- আপনার দেশে Gemini API পাওয়া যায় কিনা দেখুন।
- নতুন একটি কী বানিয়ে আবার চেষ্টা করুন।

## ফ্রি সীমা সম্পর্কে

গুগলের ফ্রি টিয়ারে দৈনিক সীমা আছে। সীমা পেরিয়ে গেলে শুনছি আপনাকে জানায়, আর সীমা রিসেট হলে আবার কাজ করে। সর্বশেষ সীমা জানতে Google AI Studio দেখুন।

## কী কোথায় থাকে?

আপনার কী আপনার নিজের পিসির Windows Credential Manager-এ থাকে। এটি এই ওয়েবসাইটে পাঠানো হয় না।
